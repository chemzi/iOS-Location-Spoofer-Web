## Why

国外选点时，默认高德底图在东京、纽约返回纯色瓦片，现有 CARTO 国际底图无 Key 时返回 `API KEY REQUIRED` 占位图。配置高德 Key 后所有地名查询固定走高德，切换底图也不会启用全球搜索，导致国外地图和地名搜索均不可用或难用。

## What Changes

- 将无额外 Key 的 OpenStreetMap 标准地图作为默认全球街道底图，保留国内高德、国内卫星和现有 Esri 全球卫星；记住用户图层选择并为加载错误提供明确提示。
- 搜索增加独立的“全球 / 国内”范围，默认全球；全球搜索复用 Photon 开源地理编码服务，国内继续使用已配置高德。搜索范围不再取决于是否配置高德 Key 或当前底图。
- 针对实测的中文海外地名歧义，增加小型、明确的常用别名表（东京、东京涩谷/涩谷、纽约），显示结果的国家/城市；其他中文查询无结果时提示尝试当地文字或英文，不承诺通用自动翻译。
- 通过受现有 Token 保护的同源 `/search` Pages Function 统一搜索结果，提供有界超时、轻量节流、短期查询缓存以及可配置全球搜索服务地址。
- 保留统一 WGS-84 坐标、合法经度归一化、点击“锁定”才保存的位置流程，覆盖搜索结果跳转、图层切换、收藏跳转。
- 先打通“搜索涩谷 → 显示街道地图 → 手动选点 → 锁定 → loc.json 读回”的最小真实路径，再扩展其他地点与异常验收。

## Capabilities

### New Capabilities

- `global-map-picker`: 全球底图选择、独立搜索范围、结果定位和已有坐标保存协议的兼容行为。

### Modified Capabilities

无现有 OpenSpec 主规格。本变更首次为上述界面行为建立规格。

## Impact

- 预期修改 `public/index.html`，新增 `functions/search.js`，按需修改已有配置注入及文档、增加针对性测试；沿用 Leaflet 和现有 Cloudflare Pages/KV。
- 不修改 `location-spoofer.js`、Shadowrocket 模块、证书、Token 语义、`/set` 与 `/loc.json` 对外协议，不迁移收藏或既有坐标。
- 默认方案不购买服务、不注册账号、不部署自托管地理数据库。公共 OSM 瓦片与 Photon 无 SLA，必须保留归属标注、浏览器缓存和适度使用；不可批量抓瓦片、离线预取或无界重试。
- 本计划和最小工程规范草稿已获用户批准实施（见 design.md 的批准记录），正式 `ENGINEERING_STANDARD.md` 已加入功能分支。交付可审查的 PR；生产合并和部署仍须另行授权。
